# 代码功能分析：Python → C++ 映射

本文档分析原 Python/pygame 版《坦克大战》的各文件、类与函数功能，并给出到 C++/DirectX 11 版的完整映射关系。

## 一、原版 Python 代码结构

原版位于 `TankGame/TankWar/`，共 4 个核心文件：

| 文件 | 职责 | 行数 |
|------|------|------|
| `main.py` | 程序入口 | 6 |
| `settings.py` | 游戏常量与地图数据 | 87 |
| `sprites.py` | 精灵类体系（基类/子弹/坦克/墙） | 236 |
| `tank_war.py` | 游戏主类（地图/输入/碰撞/渲染循环） | 205 |

此外 `resources/` 存放图片与音效，`tools/` 为个人辅助工具（不属于游戏本体，未转写）。

## 二、文件级映射

| Python 文件 | C++ 文件 | 说明 |
|-------------|----------|------|
| `main.py` | `src/main.cpp` | 入口：原版创建 `TankWar` 并 `run_game()`；C++ 版创建 Win32 窗口、初始化 `Game` 并运行 |
| `settings.py` | `src/Settings.h` | 常量、方向、资源路径、`MAP_ONE` 地图 |
| `sprites.py` | `src/Sprites.h/.cpp` + `src/Rect.h` | 精灵类体系；`Rect.h` 对应 `pygame.Rect` |
| `tank_war.py` | `src/Game.h/.cpp` | 游戏主类 `TankWar` → `Game` |
| （pygame.display/screen） | `src/Renderer.h/.cpp` | 窗口/渲染，见「新增模块」 |
| （pygame.image.load） | `src/TextureLoader.h/.cpp` | 图片解码，见「新增模块」 |
| （pygame.mixer.music） | `src/Audio.h/.cpp` | 音效播放，见「新增模块」 |

## 三、`settings.py` → `Settings.h` 映射

| Python 常量 | C++ 常量 | 说明 |
|-------------|----------|------|
| `FPS = 60` | `FPS` | 帧率 |
| `BOX_SIZE = 50` | `BOX_SIZE` | 单位格子大小 |
| `SCREEN_RECT`（950×650） | `SCREEN_WIDTH` / `SCREEN_HEIGHT` | 用两个整型替代 Rect |
| `LEFT/RIGHT/UP/DOWN` | `LEFT/RIGHT/UP/DOWN` | 方向常量 0-3 |
| `HERO/ENEMY` | `HERO/ENEMY` | 坦克类型 |
| `HERO_SPEED/ENEMY_SPEED/BULLET_SPEED` | 同名 | 速度 2/1/5 |
| `ENEMY_COUNT = 5` | `ENEMY_COUNT` | 敌方数量 |
| `RED_WALL/IRON_WALL/WEED_WALL/BOSS_WALL` | 同名 + `WATER` | 墙类型（补充 `WATER=4`） |
| `MAP_ONE`（13×19） | `MAP_ONE` | 地图，逐值一致 |
| `HERO_IMAGES` / `ENEMY_IMAGES` | 同名数组 | 4 方向贴图路径 |
| `WALLS`（`os.listdir` 排序） | `WALLS[6]` | 显式列出 `0.png`~`5.png`，避免依赖目录遍历顺序 |
| `BOOMS`（`os.listdir`） | `BOOMS[8]` | 显式列出 `blast1.gif`~`blast8.gif` |
| `BOOM_MUSIC/FIRE_MUSIC/HIT_MUSIC` | 同名 | 音效路径 |

> **新增常量**：`TANK_SIZE=40`、`BULLET_SIZE=3`、`BOOM_SIZE=40`，来源于资源图片的实际像素尺寸（详见转写说明）。

## 四、`sprites.py` → `Sprites.h/.cpp` 类映射

### 继承体系对照

```
Python (pygame.sprite.Sprite)          C++
─────────────────────────────          ─────────────────────────────
BaseSprite  ────────────────────────→  BaseSprite（含 is_alive、爆炸状态）
 ├─ Bullet  ────────────────────────→  Bullet
 ├─ TankSprite  ───────────────────→  TankSprite
 │    ├─ Hero  ────────────────────→  Hero
 │    └─ Enemy  ───────────────────→  Enemy
 └─ Wall  ─────────────────────────→  Wall
```

### 方法/成员映射

| Python | C++ | 功能说明 |
|--------|-----|----------|
| `BaseSprite.update()` | `BaseSprite::update()` | 按方向移动（LEFT/RIGHT 改 x，UP/DOWN 改 y） |
| `self.image` / `self.rect` | `texture` + `textureW/H` / `rect` | 纹理引用与位置/碰撞矩形 |
| `Bullet.__init__` (speed=5) | `Bullet::Bullet()` | 子弹速度与 3×3 尺寸 |
| `TankSprite.shot()` | `TankSprite::shot()` | 发射子弹（上限 3 发、按方向在边缘生成、我方播放 fire 音效） |
| `TankSprite.__remove_sprites()` | `removeOutOfScreenBullets()` | 移除飞出屏幕的子弹 |
| `TankSprite.move_out_wall()` | `moveOutWall()` | 碰撞后把坦克推出墙体（+2px） |
| `TankSprite.boom()` | `startExplosion()` + `updateExplosion()` | 爆炸动画（**改为非阻塞**） |
| `TankSprite.kill()` | `TankSprite::kill()` | 标记死亡 + 启动爆炸 |
| `Hero.__init__` | `Hero::Hero()` | 类型/速度/初始位置（底部、中心偏左 2 格） |
| `Hero.__turn()` | `Hero::turn()` | 按方向切换贴图 |
| `Hero.hit_wall()` | `Hero::hitWall()` | 检测屏幕边界 |
| `Hero.update()` | `Hero::update()` | 未碰墙才移动并转向 |
| `Enemy.__init__` | `Enemy::Enemy()` | 随机方向、`terminal` 里程 |
| `Enemy.random_turn()` | `Enemy::randomTurn()` | 随机转向（避开当前方向） |
| `Enemy.random_shot()` | `Enemy::randomShot()` | 1/60 概率射击 |
| `Enemy.hit_wall_turn()` | `Enemy::hitWallTurn()` | 碰屏幕边界回退 + 随机转向 |
| `Enemy.update()` | `Enemy::update()` | 随机射击 + terminal 递减移动 |
| `Wall.kill()` | `Wall::kill()` | 生命 -1，归零时爆炸销毁 |
| `pygame.sprite.collide_rect()` | `Rect` 的 `Intersects()` | 矩形相交（严格比较，相邻不算碰撞） |
| `pygame.sprite.Group()` | `std::vector<std::unique_ptr<T>>` | 精灵集合 |

## 五、`tank_war.py` → `Game.h/.cpp` 映射

| Python 方法 | C++ 方法 | 功能说明 |
|-------------|----------|----------|
| `__init__` | 成员声明 + `Init()` | 渲染器、纹理、精灵的初始化 |
| `__init_game()` | `main.cpp`（窗口/COM） | pygame 模块初始化 → Win32 窗口 + `CoInitializeEx` |
| `__create_sprite()` | `createSprites()` | 创建 hero、5 个 enemy、绘制地图 |
| `__draw_map()` | `drawMap()` | 遍历 `MAP_ONE` 创建墙体 |
| `__check_keydown()` | `OnKeyDown()` | 方向键设置方向/移动状态，空格发射 |
| `__check_keyup()` | `OnKeyUp()` | 松开方向键停止移动 |
| `__event_handler()` | `main.cpp` 的 `WndProc` + 消息泵 | 事件分发 |
| `__check_collide()` | `checkCollide()` | 子弹撞墙/坦克、坦克撞墙等全部碰撞 |
| `__update_sprites()` | `updateSprites()` + `render()` | 更新（移动/爆炸）与渲染（叠放顺序） |
| `run_game()` | `Run()` | 主循环：消息 → 碰撞 → 更新 → 渲染 → 帧限流 |
| `__game_over()` | `Run()` 退出 + `Shutdown()` | 结束清理 |

## 六、新增模块（无 Python 直接对应）

| 模块 | 对应原版能力 | 职责 |
|------|-------------|------|
| `Renderer` | `pygame.display` + `screen.blit` | D3D11 设备/交换链、内嵌 HLSL 着色器（正交投影）、带纹理四边形批量绘制 |
| `TextureLoader` | `pygame.image.load` | WIC 解码 PNG/GIF（GIF 取首帧），生成 D3D11 纹理 SRV |
| `Audio` | `pygame.mixer.music` | `PlaySoundW` 异步播放 WAV |
| `Rect` | `pygame.Rect` | 矩形结构 + `Intersects` 相交判定 |

## 七、碰撞检测逻辑对照

原版 `__check_collide` 的 5 个步骤与 C++ `checkCollide` 一一对应：

1. 屏幕边界检测（`hero.hitWall()` / `enemy.hitWallTurn()`）
2. 子弹撞墙（红墙：墙毁+子弹毁；铁墙：仅子弹毁；老巢：游戏结束；草/海：穿过）
3. 坦克撞墙（红墙/铁墙/老巢不可穿越 → 推出墙外，敌方额外随机转向）
4. 我方子弹撞敌方坦克（同归于尽）
5. 敌方子弹撞我方坦克（我方阵亡）

渲染叠放顺序同样保留：**敌弹 → 敌坦克 → 我弹 → 我坦克 → 墙**（草绘制在坦克之上形成隐蔽效果）。
